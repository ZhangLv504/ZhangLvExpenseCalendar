# 个人消费记录 App（Android / Qt 6）基础需求文档

> 本文档定义最基础的 MVP 需求与技术边界；后续细化设计与新增需求在开发迭代中逐步补充。

## 1. 项目定位

一款**个人自用、100% 离线**的 Android 原生消费记录（记账）App。核心目标：打开即记、本地持久化存储、账目准确、无多余权限。

## 2. 技术路线（硬约束）

- **框架**：Qt 6.8.3（`Core / Gui / Quick / QuickControls2 / Sql`）+ QML + C++17 + CMake
- **存储**：本地 SQLite（`QSQLITE`），所有金额统一以 **`int64_t`（单位：分）** 存储与计算，禁止使用浮点数
- **Android 适配**：仅在必要时（如 SAF 文件导入导出）使用少量 Java/JNI，不申请网络与敏感存储权限
- **平台**：Android（交付 `arm64-v8a` APK，竖屏、简体中文）

## 3. 基础功能（MVP）

1. **记一笔**：录入金额、类型（支出/收入）、分类、日期时间、备注，保存到本地 SQLite。
2. **明细管理**：按月查看消费明细列表与当月收支汇总；支持编辑和删除已有记录。
3. **基础分类**：内置常用支出/收入分类，支持后续扩展自定义分类。
4. **基础统计与导出（后续迭代）**：按月/分类汇总统计、基于 Android SAF 的 CSV 导出与备份。

## 4. 明确不做

iOS、账号登录、云同步、广告、联网功能、自动抓取微信/支付宝账单、Root 或无障碍服务。
